# STEEL-in-Rust validation letter (draft)

`main.tex` is a first draft of an MNRAS letter assembled from the
port-validation work in `docs/RESULTS_REPRODUCTION.md`,
`docs/PORT_CORRECTIONS.md`, and `docs/VALIDATION.md`. All numbers and
figures are real, regenerated by the scripts in `Scripts/Validation/`;
the prose is a first pass and wants an author read-through, not a
final draft.

## Compiling

Requires `mnras.cls`/`mnras.bst` (Royal Astronomical Society / Oxford
University Press house style). On a system with TeX Live's
`texlive-publishers` package (or on Overleaf, which bundles the class
by default), this is:

```
pdflatex main.tex
pdflatex main.tex   # second pass to resolve cross-references
```

No bibtex step is needed — the bibliography is a hand-written
`thebibliography` block, not a `.bib` file, since the reference list
is short.

## What's included vs. left out

Six figures are embedded, one representative panel per theme rather
than all ~30 reproduced in `Figures/PortValidation/`: the headline
satellite SMF (numerical fidelity), the frozen-model sweep (structural
correctness against the paper's actual comparison axis), both mass-track
decompositions (PyMorph and cmodel — the latter reproduces the paper's
own "internally non-physical" finding), and the pair-fraction
sensitivity sweep (Paper 3's actual result, not just its input
diagram). Swap in others from `Figures/PortValidation/` and
`docs/RESULTS_REPRODUCTION.md`'s per-figure notes as needed.

## Things to check before submitting anywhere

- Author list: only P. J. Grylls is listed; add/confirm co-authors.
- The defect catalogue in §5.2 picks five of the ~30 entries in
  `docs/PORT_CORRECTIONS.md` by consequence to a published figure —
  worth a second pass to confirm these are the right five to headline.
- No figure in this draft carries an observational data overlay
  (SDSS/Illustris/Mundy et al.) by design — see the note at the end of
  §4 for why, but confirm that framing before submission.
- Wall-clock numbers (§5.3) are single-process, single-configuration;
  `docs/VALIDATION.md` §4 lists the caveats.
